# 01 — 車輛提醒中心與到期狀態

**What to build:** 使用者可在單一提醒中心檢視既有服務項目提醒與手動建立的車輛提醒，依目前里程和本地日期看見正常、即將到期或逾期狀態，並能完成或延後提醒，而不改變原始到期條件。

**Blocked by:** None — can start immediately.

**Status:** completed

- [x] 服務項目、手動里程與手動日期提醒可在提醒中心以車輛、來源、到期條件與狀態顯示。
- [x] 到期狀態在本地資料與目前里程變動後正確重建；空白或不足資料不產生誤導狀態。
- [x] 使用者可完成或延後 1 天、3 天、7 天或指定日期，且延後不改寫原始到期條件。
- [x] 全部行為有 domain、Room／Repository、ViewModel 與 Compose 驗收證據。
