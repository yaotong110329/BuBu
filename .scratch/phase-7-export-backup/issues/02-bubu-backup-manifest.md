# 02 — `.bubu` 完整備份與格式驗證

**What to build:** 使用者可手動建立不加密的 `.bubu` ZIP 備份，包含可還原的完整資料、提醒狀態與所有引用附件；備份清楚提醒使用者妥善保管，且具有可驗證的版本與完整性資訊。

**Blocked by:** None — can start immediately.

**Status:** completed

- [x] 備份包含完整資料庫內容、使用中／封存車輛、保留期限內垃圾桶資料、提醒規則與完成／延後狀態，以及所有引用附件；不包含 App 偏好與可重新計算資料。
- [x] `manifest.json` 記錄格式與 App 版本、建立時間、資料／附件數量，以及每個檔案的安全相對路徑、大小與 SHA-256。
- [x] 以私有暫存區原子建立並驗證 `manifest.json`、資料與附件後才輸出 `.bubu`，且不要求未授權的廣泛檔案權限。
- [x] 以 unit、Room／Repository 與檔案測試驗證備份內容、附件清單、雜湊、格式版本與失敗清理。
