# 03 — 備份解析、完整性驗證與還原預覽

**What to build:** 使用者選取 `.bubu` 後，可先看見備份日期、版本、車輛、紀錄、提醒、附件與總大小；任何不安全或不完整備份都會在未修改現有資料前被拒絕。

**Blocked by:** 02 — `.bubu` 完整備份與格式驗證.

**Status:** completed

- [x] 驗證 ZIP 路徑安全性、重複或未宣告檔案、檔案大小、SHA-256、缺失附件與 `formatVersion`，並拒絕高於 App 支援版本的備份。
- [x] 顯示可理解的還原預覽與「完全覆蓋、不支援合併」確認資訊；驗證、解壓或空間檢查失敗時保留目前資料不變。
- [x] 較舊備份格式使用明確逐版遷移契約；不建立 Drivvo 或 CSV 反向匯入功能。
- [x] 以損壞附件、摘要不符、不安全路徑、未知版本與正常備份測試驗證拒絕與預覽行為。
