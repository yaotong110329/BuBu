# 05 — 設定頁備份管理與復原備份

**What to build:** 使用者可從設定頁安全進入 CSV 匯出、完整備份、還原與最新復原備份管理，並可管理每月備份提醒，而不讓設定偏好混入可還原使用者資料。

**Blocked by:** 01 — CSV 報表 ZIP 匯出; 04 — 完全覆蓋還原與失敗回復.

**Status:** completed

- [x] 設定頁提供 CSV 匯出、完整備份、還原、最新復原備份匯出／刪除與每月備份提醒的清楚入口與確認流程。
- [x] 資料分享使用使用者明確選取的檔案位置，並在取消、權限拒絕與 I/O 失敗時顯示具體錯誤且不遺留不完整檔案。
- [x] 刪除復原備份只影響 App 私有復原檔，不會刪除使用者提供的原始備份或其他資料。
- [x] 以 ViewModel、Compose 與裝置測試驗證入口、確認、取消、錯誤與復原備份生命週期。
